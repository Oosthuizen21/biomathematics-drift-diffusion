# Speed vs accuracy tradeoff using a drift diffusion model


## Overview:

This project uses MATLAB to simulate the Drift Diffusion Model and represents the speed-accuracy trade off in decision making.
The model represents evidence accumulation to a decision boundary, using different drift rates for different difficulty levels.

## Features:

- Simulates evidence accumulation over time
- Represents 3 different difficulty levels (Easy , Medium, Hard)
- Visualizes decision boundaries
- Uses experimental RT and accuracy data

## Installation and Usage:

1. Download this repository as a zip file by first clicking the green code button, and then selecting download zip file.
2. Ensure that both the MATLAB script and Excel data spreadsheet (bb591b8b5f31c436aac535c6a7e9cc66_data (1).xlsx) are saved in the same folder
